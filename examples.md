# Cursor Examples

Try these prompts after installing LearnOneTech MCP in Cursor:

- Search LearnOneTech for Samsung FRP troubleshooting guides.
- Find articles about Android apps and mobile troubleshooting.
- Show the latest LearnOneTech articles.
- Find the article about a specific Samsung model.
- Read the full LearnOneTech article with a specific slug.
- List LearnOneTech categories related to Android.
- Search LearnOneTech pages for a specific troubleshooting topic.

The MCP retrieves publicly available content from LearnOneTech.com through its WordPress REST API.
